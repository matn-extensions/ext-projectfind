# Global Project Search

Blazing-fast multi-threaded regex and text search across the entire project workspace (Ctrl+Shift+F)

## Details
- **Identifier**: `matn.ext.projectfind`
- **Version**: `1.0.0`
- **Category**: `tools`

## Installation
Inside Matn Editor, open the Extensions Marketplace (<kbd>Ctrl+Shift+X</kbd>), search for **Global Project Search**, and click **[Install]**.

Alternatively, install directly from GitHub:
```
https://github.com/matn-extensions/ext-projectfind
```
